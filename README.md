Dolt Dashboard

The DuoRide Dashboard is a comprehensive platform designed for both users and service providers. It includes the following features:

User Dashboard: Users can easily browse available services and book appointments through an intuitive interface.

Provider Dashboard: Service providers have their own dashboard to view incoming bookings, accept or manage appointments, and keep track of their schedule.

Marketplace & Orders: The repo also includes a marketplace feature where users can explore different services and manage their orders all in one place.
